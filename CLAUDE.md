# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

Hugo static site for the **Papers of the War Department** (wardepartmentpapers.org), migrated from Omeka S. The repo root *is* the Hugo project root (it was relocated here from the `chnm/sustainability` monorepo's `pwd/` subdirectory in 2026-09; there is no `hugo/` subfolder). Content: ~42,880 documents, ~25 editorial pages, 240 news posts. Media is served from object storage, not from the repo.

## Build & Serve Commands

`justfile` is canonical.

```bash
just build          # ulimit -n 65536 && hugo --minify, then npx pagefind --site public
just serve          # hugo server --bind 0.0.0.0 --poll 1s (no search index)
just serve-pagefind # build + pagefind --serve, for testing search locally
just index          # npx pagefind --site public (index only)
just test           # uv run pytest -q (72 tests in tests/)
just fix-images --dry-run   # scripts/fix_multipage_images.py
just fetch-pages / fetch-items / fetch-media   # Omeka API (VPN only)
```

Requires Hugo extended v0.128.0+ (built with v0.164), Node (Pagefind via `package.json`), and `uv` (Python 3.13). The `ulimit` is required — 43k pages exhaust the default macOS fd limit.

Python scripts run under `uv` (`uv run python3 scripts/…`). Data-munging scripts patch frontmatter with **minimal-diff regex string surgery** (never `yaml.dump`, which reorders/requotes keys across ~43k files) — follow that pattern.

## Architecture

### Content

| Type | Count | Directory | Layout |
|------|-------|-----------|--------|
| Document | ~42,880 | `content/document/{omeka_id}.md` | `layouts/document/single.html`, `list.html` |
| Editorial page | ~25 | `content/{slug}.md` (`type: page`) | `layouts/_default/single.html` |
| News post | 240 | `content/news/{wp_post_id}.md` (`type: news`) | `layouts/news/` |
| Search | 1 | `content/search.md` (`layout: search`) | `layouts/_default/search.html` |
| Transcription dashboard | 1 | `content/transcription-dashboard.md` | `layouts/transcription-dashboard/single.html` |

**Document is the only item type with pages.** Collections and repositories are *not* content types — they were denormalized into document frontmatter and exposed as taxonomies. Image, Name, Microfilm, and Publication items were dropped entirely.

Document frontmatter: `omeka_id`, `title`, `description`, `date`/`year`/`month`/`day`, `authors`, `recipients`, `collections`, `collection_id`, `repositories`, `doc_types`, `sent_from`, `document_number`, `omeka_image_id`, `images` (ordered file list), `num_pages`, `notable_persons/locations/items` (plain lists, displayed but not taxonomies). Human transcription text is the markdown body.

### Taxonomies (`hugo.toml`)

`authors`, `recipients`, `collections`, `repositories`, `doc_types` (documents) and `categories` (news). URLs: `/authors/{slug}/`, etc. `notable_*` fields were deliberately **not** made taxonomies (tens of thousands of single-use free-text terms) — see `DEVNOTES.md`.

### Images (microfilm reel model)

Each document's `images:` list is inline in frontmatter and rendered from `site.Params.mediaBaseURL` (`https://obj.rrchnm.org/wardepartmentpapers.org`) as `/files/{square,large,original}/{filename}`. Nothing under `static/` holds media. `omeka_image_id` points at a shared microfilm reel; `data/media_map.json` maps reel → ordered files and is used only by the repair scripts (`fix_multipage_images.py`, `apply_viewer_harvest.py`, `fix_suffix_viewers.py`), not by templates. Design notes: `docs/superpowers/specs/`.

### Transcriptions

- Human: markdown body of the document file.
- AI: `data/transcriptions_ai.json`, keyed by `omeka_id` (30,479 entries; the run is **complete**). Generated by `_transcription/transcribe.py` (`claude -p`, Claude subscription) — runbook in `_transcription/README.md`. Its output `_transcription/transcriptions.json` is manually merged into `data/transcriptions_ai.json`. `scripts/transcribe.py` is an alternate SDK/API-key path.
- `data/transcription_dashboard.json` feeds `/transcription-dashboard/`; rebuild it with `uv run python3 scripts/build_transcription_dashboard.py` after any transcription sync (it is not rebuilt automatically).
- The root-level `transcriptions.json` (7,190 entries, April 2026 Opus run) is a stale leftover, not read by anything.
- Public methodology page: `content/ai-transcription-methodology.md`.

### Search

Pagefind, indexed post-build over all of `public/` (`just build`, and the Dockerfile). UI is `layouts/_default/search.html` + `static/js/search-pagefind.js`.

### URL compatibility

Documents carry **no** Hugo aliases (removing ~88k redirect files). Legacy Omeka `/s/home/...` URLs are 301'd by `redirects.caddy`, imported into Caddy by the Dockerfile. Editorial pages keep `aliases: [/s/home/page/{slug}]` and news posts keep `aliases: [/news/?p={id}]` in frontmatter.

### Deployment

`Dockerfile` (stagex images): `npm ci` → `hugo` → `pagefind` → Caddy serving `/srv` with `redirects.caddy`. `.github/workflows/cicd.yml` calls the shared `chnm/.github` Hugo workflow on push to `main` (prod: wardepartmentpapers.org) and `preview` (dev: pwd.dev.chnm.gmu.edu). `/files/*` → object storage is handled by the fronting web server, not Caddy.

## Known Constraints & Gotchas

- Omeka S API is at `https://omeka.wardepartmentpapers.org/api/` (VPN only); the old `www.` host 302→404s. Fetch scripts are only needed to re-pull content from Omeka; everything is already in `content/`.
- `markup.goldmark.renderer.unsafe = true` is required — editorial and news pages contain raw HTML.
- Editorial pages with `outdated: true` in frontmatter render an "outdated" notice aside (`layouts/_default/single.html`); 12 pages use it.
- `layouts/partials/head.html` embeds the Matomo tracker (stats.rrchnm.org, site id 4) — intentional, keep it.
- `layouts/_default/baseof.html` carries the CHNM sustainability banner ("static copy of the final website") above the header; it is the shared snippet from `chnm/sustainability/_snippets`.
- `get_all_literals()` in `fetch_items.py` must `.strip()` values — the API returns multi-valued properties with leading spaces.
- `uv run pytest` must pass (72 tests) before committing script changes.
